# Инструкция для партнеров

По входу в административный интерфейс пользователь оказывается на странице `Задачи`. На странице отображаются задачи к выполнению.

Если при входе в административный интерфейс сервис неактивен, будет предложено [активировать работу](#активациядеактивация-сервиса).

Для того чтобы активировать звуковые уведомления при появлении новых задач, необходимо нажать левую кнопку мыши в любой части интерфейса.

## Задачи

В строке заказа указывается сумма. Может указываться банк карты клиента.

Если на момент попытки взять задачу в работу над ней уже работает другой пользователь, будет показано уведомление с ошибкой.

### Прием

Обозначаются значком 🡣 зеленого цвета.

Задача появляется после того как клиент создал заказ и подтвердил оплату.

#### Последовательность выполнения
1. В строке выбранного заказа нажать на кнопку `Одобрить`.
2. Проверить что средства, поступившие на карту, находятся в пределах указанного диапазона.
3. Нажать на кнопку `Одобрить`.

### Выплата

Обозначаются значком 🡡 красного цвета.

Задача появляется после того как клиент создал заказ.

#### Последовательность выполнения
1. В строке выбранного заказа нажать на кнопку `Выплатить`.
2. Выплатить необходимую сумму на карту клиента.
3. Выбрать карты и ввести суммы, которые были выплачены с этих карт.
4. Прикрепить чеки к картам, которые того требуют.
5. Нажать кнопку `Выплатить`.

В случае если выплату выполнить невозможно, в строке заказа нажать на кнопку `Отказаться`. В появившемся модальном окне ввести причину и нажать на кнопку `Закрыть заказ`.

### Навигация

Общее количество задач отображается в пункте меню, рядом с названием. 

Количество задач по типам и ссылки, ведущие на страницы с задачами по типу, отображаются в правой стороне пункта меню.

Также переход на страницу с определенным типом задач возможен по нажатию кнопки соответствующей ссылки в хидере.

## Заказы

Для просмотра истории доступных заказов необходимо перейти в пункт меню `Заказы`.

## Управление картами

### Пулы

Пулы представляют собой наборы карт.

Для просмотра доступных пулов карт необходимо перейти на страницу `Источники->Пулы`.

#### Редактирование пула

Находясь на странице пулов, нажать иконку редактирования ✏️ в строке нужного пула.

Доступно изменение имени пула и статуса (с указанием причины изменения).

Для сохранения измененной информации необходимо нажать на кнопку `Сохранить`.

### Карты

Для просмотра доступных карт необходимо перейти на страницу `Источники->Карты`.

### Создание карты

1. Нажать на кнопку `Добавить`.
2. Установить статус и причину изменения, если необходимо.
3. Ввести название, номер.
4. Выбрать банк карты и пул.
5. Нажать кнопку `Сохранить`.

### Импорт карты

1. Нажать на кнопку `Импортировать`.
2. Выбрать банк, пул.
3. Ввести данные по картам в формате `Номер;Название`. Каждая карта с новой строки.
4. Нажать кнопку `Сохранить`.

## Активация/деактивация сервиса

При отключенном сервисе клиенты не могут создавать заказы на прием или выплату.

Для задания настроек активности сервиса необходимо перейти в пункт меню `Настройки->Активация работы`:

1. `Статус` - определяет статус сервиса (Работает/Остановлен).
2. `Время автоматической остановки работы` - если указано - по достижении указанного времени происходит отключение работы сервиса.

Возможность активации/деактивации сервиса доступна в хидере. При активном сервисе, там же отображается время автоматической остановки работы.
